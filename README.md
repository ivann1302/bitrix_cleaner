# CRM Cleaner

Браузерное приложение для проверки и массового удаления старых лидов или сделок Bitrix24. Лимит — 3 000 записей за операцию.

## Статус

Документация размещена в проекте, базовые frontend-зависимости установлены и зафиксированы в `package-lock.json`. Каркас, интеграция, сборка и тесты приложения ещё не созданы. Проверенное состояние хранится в [docs/STATUS.md](docs/STATUS.md).

## Архитектура

Используем React + TypeScript + Vite, библиотеку Bitrix24 в iframe и локальный checkpoint операции. SprintHost отдаёт файлы; PHP используется только для минимальной страницы открытия/установки. Собственного backend обработки CRM, серверной БД и cron нет. Node.js нужен только для локальной сборки.

Закрытие вкладки прекращает отправку новых запросов; отправленные могут завершиться. Продолжение требует сохранившихся локальных данных, проверки результатов и явного действия пользователя. CSV не является полной резервной копией CRM.

## Начало работы

1. Прочитать AGENTS.md, docs/STATUS.md и этап 1 плана.
   Затем проверить обнаружение навыков по docs/SKILLS.md и прочитать применимые стандарты кода.
2. Выбрать первую сущность: лиды или сделки.
3. Создать локальный каркас и MockBitrixAdapter без реальных запросов CRM.
4. После успешного запуска дополнить ниже точные проверенные команды.
