# CRM Cleaner

Браузерное приложение для проверки и контролируемой массовой очистки старых проигранных сделок и неуспешных лидов Bitrix24. Лимит одного полного preview — 3 000 записей одного типа.

## Статус

На искусственных данных для сделок и лидов работают фильтры, полный preview до 3 000 записей, исключения, CSV, подтверждение точного набора, демо-удаление, пауза, остановка и отчёт по каждому ID. Реальный read-only адаптер через официальный SDK поддерживает оба типа и покрыт локальными контрактными тестами, но настоящий iframe/портал ещё не проверялся. Реального удаления Bitrix24 нет. Проверенное состояние хранится в [docs/STATUS.md](docs/STATUS.md).

## Архитектура

Текущий срез использует React + TypeScript + Vite, официальный `@bitrix24/b24jssdk`, entity-aware `BitrixDealReadAdapter`, локальный `MockBitrixAdapter` и независимый последовательный исполнитель; PHP только отдаёт собранный `index.html`. Верхнеуровневый запуск открывает demo, iframe инициализирует SDK и остаётся только для чтения. Хранилище использует native IndexedDB, блокировка — Web Locks; оба изолированы по типу CRM. При недоступности этих API demo-запуск удаления блокируется. Собственного backend обработки CRM, серверной БД, cron и постоянного Node-процесса нет.

Закрытие вкладки прекращает отправку новых запросов; отправленные могут завершиться. Автоматического продолжения и восстановления операции нет: при возврате показываем отчёт и предлагаем сверку результатов и новый поиск. CSV не является полной резервной копией CRM. Демо-данные сбрасываются при перезагрузке, но последний локальный отчёт сохраняется; он не доказывает никаких изменений в Bitrix24.

Для демонстрации в актуальном Chrome: `npm run dev`, выбрать сделки или лиды, задать дату до `2026-01-31`, выполнить поиск, исключить строку, скачать CSV и перейти `К подтверждению`. Красная кнопка затрагивает только искусственные записи в памяти. Пока операция активна, фильтры и выбор типа заблокированы; доступны пауза и остановка. Список действует 10 минут, повтор того же поиска требует нового сбора.

## Начало работы

1. Прочитать AGENTS.md, docs/STATUS.md и этап 1 плана.
2. Выполнить `npm install`.
3. Запустить локальный demo командой `npm run dev`.
4. Перед изменениями прочитать утверждённую спецификацию и применимые стандарты кода.
