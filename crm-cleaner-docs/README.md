# CRM Cleaner

Браузерное приложение для проверки и массового удаления старых лидов и сделок Bitrix24. Лимит — 3 000 записей за операцию.

## Статус

Подготовлена документация. Каркас, интеграция, сборка и тесты приложения ещё не созданы. Проверенное состояние хранится в [docs/STATUS.md](docs/STATUS.md).

## Архитектура

Планируем React + TypeScript + Vite, библиотеку Bitrix24 в iframe и IndexedDB для локальных операций. SprintHost отдаёт файлы; PHP используется только для минимальной страницы открытия/установки. Собственного backend обработки CRM, серверной БД и cron нет. Node.js нужен только для локальной сборки.

Закрытие вкладки прекращает отправку новых запросов; отправленные могут завершиться. Продолжение требует сохранившихся локальных данных, проверки результатов и явного действия пользователя. CSV не является полной резервной копией CRM.
