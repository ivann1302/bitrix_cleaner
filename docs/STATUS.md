# Текущее состояние

Обновлено: 10 сентября 2026 года. Стадия: локальный сценарий от поиска до демо-удаления и отчёта.

## Готово

- Строгий React/TypeScript/Vite-каркас, mock-поиск, preview до 3 000 записей, пагинация и исключения.
- CSV выбранных строк всех страниц: UTF-8 BOM, кавычки/переносы/кириллица и нейтрализация формул. Это контрольный экспорт, не полный backup.
- Подтверждение неизменяемого набора ID, контекста и условий. Изменения выбора/фильтра аннулируют подтверждение; срок списка — 10 минут.
- Независимый mock-исполнитель: одна отправка за раз, сохранение намерения до вызова и результата после, максимум три попытки явно временной ошибки, пауза/остановка. Неизвестный ответ не повторяется.
- Native IndexedDB checkpoint и Web Locks между вкладками; недоступность блокирует запуск. При возврате sent становится unknown, автостарта нет.
- Демо-контекст demo.local/demo-admin: сетевых запросов и изменений Bitrix24 нет. Демо-данные сбрасываются при перезагрузке, последний отчёт сохраняется отдельно.

## Проверено локально

- `npm test`: 203 теста в 19 файлах прошли, включая подтверждение, CSV, исполнитель, parser/lock, UI и lifecycle.
- Проверка типов, ESLint и production-сборка проходят; новых зависимостей нет.
- Chrome: CSV на 44 выбранные строки; modal на 1 200/700/350 CSS px; Escape и фокус, включая просроченное подтверждение; блокировка фильтров; пауза/стоп; межвкладочный lock; изоляция контекста; прерванный отчёт без автостарта.
- Настоящая IndexedDB: чтение checkpoint второй вкладкой, отказ сохранения при abort после request success. Артефакты: `.superpowers/local-operation-checks/`.
- Независимое ревью: исправлены возврат фокуса и lifecycle при замене сервисов; критических замечаний к локальному исполнителю не найдено.

## Ограничения

- SprintHost, iframe, SDK, настоящие права и REST-методы этим этапом не реализованы/не проверены. Колонка Bitrix в матрице остаётся НЗ.
- Нет реальных ссылок на карточки, полноценного возобновления, постоянной истории или миграций старых схем. Незнакомые checkpoint отклоняются.
- 3 000 ID проверены на mock, не как замер скорости настоящего API/IndexedDB. Полная перезапись checkpoint выбрана для простоты, требует отдельного измерения перед масштабным запуском.
- Проверена текущая версия desktop Chrome. 350 CSS px не заменяет фактический zoom 200 % в iframe.

## Следующая задача

Минимальный реальный read-only адаптер по отдельному интеграционному дизайну, затем проверка на тестовом портале. Для размещения понадобятся адрес SprintHost и согласованный портал. Пароли/токены в чат не передаются. Реальные изменения CRM требуют отдельного разрешения с точным набором искусственных ID.
