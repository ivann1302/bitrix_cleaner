# Текущее состояние

Обновлено: 10 сентября 2026 года. Стадия: локальный mock-preview сделок готов и проверен.

## Готово

- Создан строгий React/TypeScript/Vite-каркас с lockfile, lint/typecheck/test/build-командами и минимальным PHP-входом.
- Реализован локальный mock-preview старых проигранных сделок: фильтры, состояния поиска, дедупликация, лимит 3 000, пагинация, исключения и точные счётчики.
- Реализован адаптивный бирюзовый интерфейс: сводка условий рядом с формой, сводка результата рядом с таблицей на широком экране, перенос сводки над таблицей при ширине до 1 100 px и одна колонка фильтров при 700 px.
- Реальных запросов Bitrix24, CSV, подтверждения, checkpoint и DELETE в коде нет.

## Проверено локально

- Node.js 24.18.0, npm 11.16.0, PHP 8.5.4 и Google Chrome 150.0.7871.124.
- `npm run typecheck`, `npm run lint`, `npm test` (46 tests), `npm run build`, `php -l public/index.php`, `php -l dist/index.php`, `cmp -s PLAN.md docs/PLAN.md` и `npm ls --depth=0` завершились успешно.
- Production-пакет содержит `index.html`, `index.php` и относительные assets. Через локальный PHP-вход `/dist/index.php` Chrome загрузил JS и CSS из `/dist/assets/` и смонтировал приложение.
- В Chrome на 1 440, 1 024 и 700 px проверены поиск, исключение и возврат строки, переход страницы и её сброс при новом поиске, предупреждение об устаревшем preview, отсутствие кнопки удаления, видимый focus ring и отсутствие горизонтального переполнения документа. На 700 px горизонтальная прокрутка остаётся внутри таблицы; проверка на CSS-ширине 350 px служит эквивалентом 200 % масштаба для 700 px, а не заменяет проверку пользовательского zoom в Bitrix24.

## Ограничения

- Не проверялись SprintHost, iframe Bitrix24, SDK, авторизация, портал и реальный read-only REST-вызов; все ячейки Bitrix в матрице остаются НЗ.
- Не реализованы и не проверены CSV, подтверждение, удаление, права администратора, checkpoint, pause/retry и реальные последствия CRM.
- Проверка выполнена в актуальном desktop Chrome. Полная поддержка браузеров и фактический zoom внутри iframe Bitrix24 остаются будущей интеграционной проверкой.
