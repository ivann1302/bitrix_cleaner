# Локальное выполнение подтверждённой операции

Продолжение утверждённого MVP по указанию пользователя работать автономно.
Корневые PRODUCT.md и PLAN.md сохраняют приоритет. Это локальная реализация,
не разрешение обращаться к живой CRM или размещать приложение.

## Решение

CSV выгружает выбранные записи всех страниц. Подтверждение копирует и замораживает
контекст, условия, ревизию, версию выбора и ID. Любое изменение фильтра или выбора
аннулирует подтверждение; срок списка — 10 минут с завершения поиска.

Исполнитель отделён от React. Последовательная отправка по одному ID выбрана как
минимальный пакет: не больше одного незавершённого запроса. Перед каждой отправкой
сохраняется состояние sent, после ответа — отдельный результат ID. Неизвестный
ответ не повторяется. Только явно временные ошибки повторяются, максимум три
попытки на ID, с ограниченной задержкой. Ошибки авторизации прекращают новые вызовы.

Пауза прекращает новые вызовы; продолжение доступно явно в текущей вкладке, пока
подтверждение актуально. Остановка окончательна для операции. Смена контекста,
отказ checkpoint и истечение списка прекращают новые отправки. Отправленный
запрос может завершиться после паузы или остановки.

Минимальный IndexedDB checkpoint содержит только версию схемы, контекст,
идентификатор операции, время, её статус и ID с числом попыток/результатами.
Одна последняя операция на контекст, без постоянной истории и токенов. Запись
считается сохранённой только после завершения транзакции. Неизвестная схема или
недоступное хранилище блокируют запуск. Web Locks удерживает блокировку контекста
на всё выполнение; отсутствие поддержки блокирует запуск, не даёт слабый fallback.

При открытии сохранённая незавершённая операция отображается как прерванная,
sent преобразуется в unknown. Автоматического продолжения нет. Новый поиск и
подтверждение обязательны, ранее неизвестные результаты предлагается сверить.

Демо-контекст явно искусственный. Только mock-транспорт доступен из приложения.
Реальный SDK и методы Bitrix24 не входят в эту локальную задачу.

## Приёмка

Тесты: точные ID после исключений; пустая/неполная/превышенная выборка; истечение;
изменение и возврат фильтра; двойной запуск; запись до отправки; частичный успех;
потеря ответа; ограниченные повторы; пауза/стоп; отказ хранилища; смена контекста;
повторное открытие без автоматических вызовов. Browser: модальный фокус и Escape,
CSV, прогресс, настоящее IndexedDB и блокировка между двумя вкладками.
