## Обозначения и порядок

НЗ — не запускалось. После выполнения указать PASS, FAIL или BLOCKED и ссылку на запись прогона. N/A допустимо только с причиной.

Mock — локальные искусственные данные без сети. Bitrix — испытание на точном согласованном портале и наборе ID. Сначала проходят соответствующие mock-проверки, затем разрешённые интеграционные тесты. Искусственно перегружать API или создавать массовые fixtures без разрешения нельзя.

## Протокол одного прогона

- Run ID и дата.
- Версия кода/commit и версия приложения.
- Среда: mock либо согласованный тестовый портал; браузер и режим хранилища.
- ID тестов и результат по каждому.
- Входной набор и ожидаемые ID; для живого теста — ссылка на согласованный состав и лимиты.
- Ожидаемые команды, фактические результаты и контрольные ID, которые должны остаться.
- Логи/скриншоты без токенов и лишних персональных данных.
- Ошибки, неизвестные результаты, ограничения и необходимые исправления.
